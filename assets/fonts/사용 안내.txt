감띠즈 글꼴 v3.000 — 한글·영문 각 4단계 굵기

구성
감띠즈 한글 / Gamttiz Korean: Light(300), Regular(400), SemiBold(600), Bold(700)
감띠즈 영문 / Gamttiz English: Light(300), Regular(400), SemiBold(600), Bold(700)
전체 8개 TTF입니다. Regular 파일은 기존 이름인 ‘감띠즈 한글.ttf’, ‘감띠즈 영문.ttf’를 사용합니다. 나머지 파일 이름에 Light, SemiBold, Bold가 붙습니다.

기존 형태 보존
한글 Regular와 Bold는 v2의 글리프 윤곽을 그대로 보존했습니다. 한글 Light는 기존 Regular의 윤곽을 얇게, SemiBold는 기존 Bold의 윤곽을 조금 얇게 조정했습니다.
이전 요청에서 한글 Regular와 Bold는 각각 사진 오른쪽 설명문과 왼쪽 큰 제목을 기준으로 제작한 서로 다른 원형입니다. 이번 작업은 그 두 원형을 바꾸지 않고 두 굵기를 추가한 것입니다.
영문은 기존의 두꺼운 글꼴 모양을 Bold로 보존했습니다. Light, Regular, SemiBold는 같은 윤곽에서 두께를 단계적으로 줄였습니다. 기존 영문 모양으로 쓰려면 Bold를 선택하세요.
문자의 기본 진행 폭(advance width)은 모든 파일에서 각 기준 파일과 동일합니다. 외곽선을 안으로 줄였으므로 검은 획의 바깥 경계는 가늘어진 만큼 작아집니다.
작은 점이나 좁은 획이 없어지거나 끊어지는 경우에는 해당 글자의 두께 감소량을 제한했습니다. 외곽선 계산 중 생기는 미세한 찌꺼기는 제거했습니다.

사용
각 언어의 4개 파일을 모두 설치하세요. Illustrator의 글꼴 목록에서 ‘감띠즈 한글’ 또는 ‘감띠즈 영문’을 선택하고 스타일에서 Light / Regular / SemiBold / Bold를 고릅니다.
이번 컴퓨터에는 8개 파일을 설치하여 기존 등록을 업데이트했습니다. 이전 글꼴 정보가 보이면 작업을 저장한 후 Illustrator를 다시 실행해 보세요.
구형 프로그램에서는 Light와 SemiBold가 별도 글꼴 이름으로 나타날 수 있습니다. 현대 타이포그래픽 패밀리 정보에는 각 언어가 하나의 가족으로 묶여 있습니다.

지원 및 확인
한글 각 굵기: 현대 한글 완성형 11,172자, 현대 조합 자모 67자, 현대 호환 자모 51자.
영문 각 굵기: 대문자 A–Z, 소문자 a–z, 숫자 0–9 및 기본 ASCII 기호.
8개 파일 모두 지원 문자 누락·빈 글리프 검사와 메타데이터 검증을 수행했습니다. 한글 완성형과 자모 분해 문자열의 출력 일치도 확인했습니다.
Windows에서 각 굵기의 실제 폰트 파일·버전·굵기 선택, 문자 매핑, 실제 EDIT 컨트롤에서의 Unicode 문자 입력을 확인했습니다.
물리 키보드 IME 조작과 Illustrator 내부 직접 입력은 별도로 검증하지 않았습니다.

제작 출처 및 제한
이미지 기반 재현 스타일이며 원본 폰트를 식별한 결과가 아닙니다. v2에서 사진에 보이는 대표 한글은 직접 윤곽을 벡터화하고, 나머지 현대 한글은 같은 계열의 자음·모음 구조로 확장했습니다.
사진에 없는 글자의 원래 형태를 복구한 것은 아니며, 저해상도 사진과 모든 크기에서 픽셀 단위로 동일한 글꼴을 보장하지 않습니다.
한글 파일의 부가 기호는 Gowun Dodum, 영문은 Jua 기반 수정본입니다. SIL Open Font License 1.1로 배포하며, 동봉한 저작권·라이선스 파일을 함께 보존하세요.

Windows 캐시 호환성
이전 글꼴과의 캐시 충돌을 방지하기 위해 레거시 글꼴 이름에는 v3가 붙습니다. 현대 타이포그래픽 패밀리 이름은 ‘감띠즈 한글’과 ‘감띠즈 영문’을 유지합니다. 프로그램에 따라 ‘감띠즈 한글 v3’ 또는 ‘감띠즈 영문 v3’로 보일 수 있습니다. 8종 모두 새 내부 식별자로 Windows 공개 사용자 글꼴 등록 및 실제 선택 검증을 통과했습니다.
