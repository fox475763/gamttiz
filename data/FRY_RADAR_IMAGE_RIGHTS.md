# FRY RADAR 이미지 표시 정책

FRY RADAR는 원문에 공개된 대표 이미지 URL을 게시글 썸네일로 표시합니다. 이미지 파일을 GitHub 저장소에 복제하지 않고 원본 출처에 연결하는 방식입니다.

**중요:** 원본 이미지가 공개되어 있고 출처를 링크했다고 해서 재사용이 자동으로 허락된 것은 아닙니다. 이미지 소유자가 사용 중지를 요청하거나 이용 조건상 허락이 필요하다면 이미지를 내려야 합니다. 이미지 사용에 관한 명시적 허락을 별도로 받은 것으로 표시하지 않습니다.

사진 URL이 없거나 불러올 수 없는 경우에는 감띠즈 자체 제작 CSS 감자튀김 그림을 대신 표시합니다. 기사 제목, 간략한 설명, 원문 링크는 계속 유지합니다.

특정 브랜드·언론사 이미지를 상업적으로 사용하려면 저작권자의 허락이나 적용 가능한 라이선스를 별도로 확인하는 것이 좋습니다.
