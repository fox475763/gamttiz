# FRY RADAR 이미지 이용 기준

## 현재 검토 결과 (2026-11-11)
- 롯데잇츠 이용약관 제25조는 회사 저작물의 영리 목적 복제·송신·출판·배포 등에 사전 승낙을 요구합니다. 이미지가 페이지에 공개되어 있는 것만으로 GAMTTIZ에 재사용 권리가 생기지 않습니다.
  https://www.lotteeatz.com/footer/clause/useterm
- 헤럴드경제 원문 사진을 제3자 사이트에서 상업용 썸네일로 사용할 수 있다는 별도 허락은 확인하지 못했습니다.
- 따라서 기존 롯데리아 2건·헤럴드경제 1건의 원본 이미지 URL을 공개 데이터에서 제거했습니다.
- 이미지를 사용할 수 없는 게시글에는 GAMTTIZ가 직접 만든 일반 감자튀김 CSS 그래픽을 표시합니다. 해당 그림은 실제 행사 사진이 아닙니다.

## 이미지 게시 승인 절차
1. 이미지 저작권자와 실제 이미지 권리 범위를 확인합니다. 브랜드가 공개한 이미지라고 해도 광고대행사·촬영자 등 다른 권리자가 있을 수 있습니다.
2. 공개 웹사이트에서 썸네일로 게시할 수 있는 서면 허락 또는 해당 용도를 허용하는 라이선스 원문을 확보합니다.
3. 승인 근거를 공개 가능한 HTTPS 주소에 보관한 후 해당 게시글에 아래 필드를 추가합니다.

```json
{
  "imageUrl": "https://example.org/licensed-image.jpg",
  "imageRights": {
    "status": "approved",
    "scope": "public-thumbnail",
    "evidenceUrl": "https://example.org/permission-or-license"
  }
}
```

4. 승인되지 않은 이미지는 자동 수집 프로그램이 삭제하며, 게시판도 이미지 표시를 차단합니다. `tools/check-site.mjs` 검사도 승인 근거 없이 `imageUrl`이 포함된 데이터를 오류로 처리합니다.
5. 출처가 링크 가능하다는 것과 이미지를 다른 사이트에 표시할 수 있다는 것은 별개의 문제입니다. 원문 기사 링크와 짧은 설명은 유지하되 사진 사용 권한은 별도로 확인합니다.
