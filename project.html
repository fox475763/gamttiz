GAMTTIZ / PROJECT INFO

감띠즈 TMI.

작은 감자튀김,
저마다의 매력.

감자튀김을 좋아하는 마음에서 시작된 14가지 캐릭터. 일러스트에서 아크릴 키링, 패키지와 감띠즈 홀더까지 이어지는 캐릭터 디자인 프로젝트입니다.

CHARACTER PROJECT

01 / THE ORIGIN

감자튀김 한 봉지에서
시작한 이야기.

반듯한 것부터 휘어진 것까지, 감자튀김의 서로 다른 생김새는 익숙하지만 쉽게 지나치는 작은 디테일입니다.

DESIGN INTENT

모양이 다르다는 건
틀린 것이 아니라
다른 매력이라는 것.

01

관찰에서 캐릭터로

굵기, 휘어짐, 튀겨진 정도, 시즈닝처럼 실제 감자튀김에서 발견할 수 있는 특징에 작은 표정과 개성을 부여합니다.

02

취향에서 공감으로

감튀 애호가에게는 익숙한 디테일을 발견하는 재미를, 처음 만나는 사람에게는 새로운 시선을 전하고자 합니다.

03

일러스트에서 일상으로

캐릭터를 키링과 홀더로 연결해 좋아하는 마음을 가방과 열쇠에 달고 다닐 수 있도록 설계했습니다.

02 / CHARACTER LANGUAGE

같은 감자튀김,
다른 개성.

감띠즈의 디자인은 형태, 표면, 관계라는 세 가지 관찰의 기준에서 읽을 수 있습니다.

01 / SHAPE

형태

곧게 뻗거나 휘어진 실루엣만으로도 감띠의 개성이 달라집니다.

02 / TEXTURE

표면

튀겨진 색, 시즈닝과 케찹은 각 캐릭터의 특징을 드러냅니다.

03 / RELATION

관계

둘이 붙어 있거나 함께 다니는 모습으로 친구들의 이야기를 표현합니다.

03 / CHARACTER ARCHIVE

14명의 감띠들.

서로 다른 생김새와 표정의 원본 캐릭터를 만나보세요. 한 명씩 눌러 특징을 확인할 수 있어요.
