# GAMTTIZ · 감띠즈

14종의 감띠 키링과 홀더를 소개하는 반응형 정적 웹사이트입니다. HTML, CSS, JavaScript만 사용하며 별도 빌드가 필요 없습니다.

## 미리보기

`index.html`을 브라우저로 열어 볼 수 있습니다. 로컬 미리보기 서버를 사용하면 SVG 일러스트도 올바른 형식으로 제공됩니다. 인스타그램 링크에는 인터넷 연결이 필요합니다.

## 사이트 구성

- 첫 화면: 감띠즈 영문 글자 애니메이션과 빨간 영역 전체의 가늘고 둥근 감튀 모양·노란 점 배경 애니메이션
- 별도 `project.html` 정보 화면: 제작자 채민석, 인스타그램 연락처, 기획 의도, 사용 글꼴, 브랜드 색상, 14종 원본 SVG 일러스트, 라이프스타일 목업 3장
- 브랜드 이야기와 홀더 소개
- 원본 제품 소개 PNG를 사용하는 14종 키링 갤러리 및 상세 보기
- 감자튀김을 먹는 취향에 관한 3문항 테스트와 캐릭터 결과
- 원본 SVG 일러스트를 사용하는 감띠 선택 카드, 최대 3종 트레이, 비밀 노트
- 공식 인스타그램 연결

애니메이션은 운영체제의 움직임 줄이기 설정을 존중합니다. 테스트 결과는 놀이용이며, 상품 주문이나 실제 세트 구성 기능은 없습니다.

## 이미지와 글꼴

제품 소개 PNG와 사용자가 추가로 제공한 캐릭터 SVG 14개는 원본 파일을 그대로 복사했습니다. 원본의 형태, 비율, 색상, 각도를 수정하지 않았습니다. SVG는 `assets/illustrations/friend-01.svg`부터 `friend-14.svg`까지 제품 순서에 맞춰 들어 있습니다. 영문 포인트에는 사용자가 만든 감띠즈 영문 글꼴을 쓰고, 한글에는 Wanted Sans Variable을 사용합니다. 두 글꼴의 사용 안내 및 라이선스 파일은 `assets/fonts/`에 있습니다.

`assets/mockups/`의 `detail-*.png`와 `collection-*.png`는 사용자가 보유한 키링 연출 목업을 그대로 복사한 것입니다. 새 `lifestyle-*.png` 3개는 생성한 빈 사진 배경으로, 사이트에서 원본 키링 PNG를 고리 접점에 맞춰 겹쳐 보여줍니다. 제품 이미지는 원본 해상도보다 작게 표시하며, 원본의 의도적인 픽셀 스타일은 흐리거나 재생성하지 않았습니다. 이 이미지는 합성 목업이며 실제 제품 사진이나 제작 과정 기록이 아닙니다.

캐릭터 상세 화면의 짧은 이야기는 제공된 제품 설명을 바탕으로 작성한 사이트용 상상 문구입니다. 공식 설정으로 확정된 내용은 아닙니다.

## GitHub Pages 공개하기

1. GitHub에서 새 공개 저장소를 만듭니다. 이름 예: `gamttiz`.
2. 이 `gamttiz` 폴더 **안의 모든 파일과 `assets` 폴더**를 저장소 최상위에 업로드합니다. `gamttiz` 폴더 자체를 한 단계 더 넣지 마세요.
3. 저장소의 **Settings → Pages → Build and deployment**에서 Source를 **Deploy from a branch**, Branch를 **main**, 폴더를 **/(root)**로 선택하고 저장합니다.
4. 배포가 끝나면 Pages 화면에 표시된 주소를 엽니다. 보통 `https://사용자이름.github.io/gamttiz/` 형태입니다.

로컬 제작본이며 GitHub 업로드와 공개 배포는 아직 수행하지 않았습니다.

## 수정 위치

- 페이지 문구와 구성: `index.html`
- 기본 레이아웃: `style.css`, `refinement.css`
- 배경·트레이·호버 애니메이션: `play.css`, `play.js`
- 프로젝트 정보 및 목업 갤러리: `project.html`, `project.css`, `project.js`
- 한글 글꼴: `site-font.css`
- 감튀 취향 테스트: `quiz.css`, `quiz.js`
- 제품 이름·설명·상상 이야기: `app.js`
- 원본 이미지와 일러스트: `assets/`

확인: 첫 화면, 모바일용 질문 화면과 SVG 선택 카드, 질문 선택 후 결과 화면을 브라우저에서 살폈습니다. 3문항의 64가지 선택 조합에서 14종 모두 결과로 나올 수 있음을 확인했습니다.
