# GAMTTIZ · 감띠즈

14종의 감띠 키링과 홀더를 소개하는 반응형 정적 웹사이트입니다. HTML, CSS, JavaScript만 사용하며 별도 빌드가 필요 없습니다.

## 미리보기

`index.html`을 브라우저로 열어 볼 수 있습니다. 로컬 미리보기 서버를 사용하면 SVG 일러스트도 올바른 형식으로 제공됩니다. 인스타그램 링크에는 인터넷 연결이 필요합니다.

## 사이트 구성

- 첫 화면: 감띠즈 영문 글자와 배경 애니메이션, 14종 원본 제품 카드 자동 넘김
- 별도 `project.html` 정보 화면: 제작자 채민석, 인스타그램 연락처, 기획 의도, 사용 글꼴, 브랜드 색상, 14종 원본 SVG 일러스트, 오른쪽에서 왼쪽으로 이어지는 라이프스타일 목업 6장
- 브랜드 이야기의 원본 제품 카드 자동 넘김과 홀더 소개
- 원본 제품 소개 PNG를 사용하는 14종 키링 갤러리 및 상세 보기
- 별도 `play.html` 체험 선택 화면
- 별도 `quiz.html` 감튀 취향 테스트: 30개 질문 중 매번 임의로 고르는 10문항, 14종 캐릭터 결과, 닮은 점과 감튀 습관, 잘 어울리는 감띠와 도움이 되는 감띠, 1080×1920 PNG 저장과 공유
- 별도 `combo.html` 감띠 홀더: 원본 SVG 일러스트를 사용하는 선택 카드, 최대 5명이 함께 들어가는 회전형 3D 홀더, 현재 각도의 1080×1920 PNG 저장과 공유, 선택한 감띠의 비밀 노트
- 공식 인스타그램 연결

애니메이션은 운영체제의 움직임 줄이기 설정을 존중합니다. 테스트 결과는 놀이용이며, 상품 주문이나 실제 세트 구성 기능은 없습니다.

## 이미지와 글꼴

제품 소개 PNG와 사용자가 추가로 제공한 캐릭터 SVG 14개는 원본 파일을 그대로 복사했습니다. 원본의 형태, 비율, 색상, 각도를 수정하지 않았습니다. SVG는 `assets/illustrations/friend-01.svg`부터 `friend-14.svg`까지 제품 순서에 맞춰 들어 있습니다. 영문 포인트에는 사용자가 만든 감띠즈 영문 글꼴을 쓰고, 한글에는 Wanted Sans Variable을 사용합니다. 두 글꼴의 사용 안내 및 라이선스 파일은 `assets/fonts/`에 있습니다.

`combo.html`의 빨간 홀더는 사용자가 제공한 `감자튀김 홀더.fbx`의 실제 메시를 변환한 `assets/holder-fbx.glb`입니다. 원본 메시의 형태를 유지하고 브랜드 빨강 재질과 조명을 적용했습니다. 선택한 캐릭터는 원본 SVG를 고해상도 투명 PNG로 렌더링한 질감을 얇은 아크릴판처럼 3D 장면 안에 배치합니다. 홀더의 실제 앞면이 캐릭터의 아래쪽을 가리며, 마우스나 터치로 돌리면 함께 돌아갑니다. 원본 SVG 자체는 변경하지 않았습니다. WebGL을 사용할 수 없는 브라우저에서는 기존의 정면 이미지 구성이 대신 표시됩니다.

3D 장면은 프로젝트에 포함한 [Three.js](https://threejs.org/) 0.180.0을 사용합니다. 라이선스는 `assets/vendor/three/LICENSE.txt`에 있습니다. 스튜디오형 환경 반사, 따뜻한 주광과 보조광, 미세한 플라스틱 표면 질감, 부드러운 접지 그림자를 적용했습니다. 이 연출은 평면 캐릭터 일러스트를 얇은 입체판으로 배치한 것으로, 캐릭터의 완전한 3D 조형 모델은 아닙니다. PNG 저장은 현재 보고 있는 회전 각도를 고해상도로 다시 렌더링합니다.

모바일 홀더 PNG 저장은 버튼을 누른 즉시 파일 다운로드를 시작합니다. 모바일 브라우저가 다운로드를 제한하면 함께 표시되는 1080×1920 이미지 미리보기를 길게 눌러 사진에 저장할 수 있습니다. 감튀 취향 테스트 결과도 같은 크기로 저장되며 모바일 저장 미리보기를 제공합니다. 파일 공유를 지원하는 브라우저에서는 운영체제 공유 메뉴로 결과 이미지를 전달할 수 있습니다.

취향 테스트 결과 링크에는 선택된 질문과 답변이 포함되어 같은 결과를 다시 열 수 있습니다. 모바일 브라우저에서 지원하면 운영체제의 공유 메뉴를 사용하고, 그 외에는 결과 문구와 링크를 복사할 수 있습니다. 인스타그램 게시물에는 저장한 PNG를 직접 올리면 됩니다.

`assets/mockups/`의 `detail-*.png`와 `collection-*.png`는 사용자가 보유한 키링 연출 목업을 그대로 복사한 것입니다. 새 `lifestyle-*.png` 사진 배경과 원본 키링 PNG를 조합해 데님 고리, 가방 고리, 지갑 고리, 테이블 장면 6개를 보여줍니다. 6장에는 세 종류의 원본 키링 이미지가 쓰입니다. 제품 이미지는 원본 해상도보다 작게 표시하며, 원본의 의도적인 픽셀 스타일은 흐리거나 재생성하지 않았습니다. 이 이미지는 합성 목업이며 실제 제품 사진이나 제작 과정 기록이 아닙니다.

캐릭터 상세 화면의 짧은 이야기는 제공된 제품 설명을 바탕으로 작성한 사이트용 상상 문구입니다. 공식 설정으로 확정된 내용은 아닙니다.

## GitHub Pages 공개하기

1. GitHub에서 새 공개 저장소를 만듭니다. 이름 예: `gamttiz`.
2. 이 `gamttiz` 폴더 **안의 모든 파일과 `assets` 폴더**를 저장소 최상위에 업로드합니다. `gamttiz` 폴더 자체를 한 단계 더 넣지 마세요.
3. 저장소의 **Settings → Pages → Build and deployment**에서 Source를 **Deploy from a branch**, Branch를 **main**, 폴더를 **/(root)**로 선택하고 저장합니다.
4. 배포가 끝나면 Pages 화면에 표시된 주소를 엽니다. 보통 `https://사용자이름.github.io/gamttiz/` 형태입니다.

로컬 제작본이며 GitHub 업로드와 공개 배포는 아직 수행하지 않았습니다.

인스타그램에는 배포 후 `https://사용자이름.github.io/gamttiz/quiz.html`과 `https://사용자이름.github.io/gamttiz/combo.html`을 각각 공유할 수 있습니다. 실제 주소는 GitHub Pages에 표시된 주소로 바꿔 사용하세요.

- 제품 이름·설명·상상 이야기: `app.js`
