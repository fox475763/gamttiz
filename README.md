# GAMTTIZ · 감띠즈

14종 아크릴 키링과 홀더를 소개하는 반응형 정적 웹사이트입니다.
HTML, CSS, JavaScript만 사용하며 별도 설치나 빌드가 필요 없습니다.

## 미리보기

`index.html`을 브라우저로 열면 사용할 수 있습니다. 인터넷 연결 없이도 제품 이미지와 갤러리가 작동합니다. 인스타그램 이동에는 인터넷 연결이 필요합니다.

## GitHub Pages 공개하기

1. GitHub에 로그인한 뒤 새 공개 저장소를 만듭니다. 이름 예: `gamttiz`.
2. `gamttiz` 폴더 **안의** `index.html`, `style.css`, `refinement.css`, `play.css`, `app.js`, `play.js`, `assets` 폴더를 저장소 최상위에 업로드하고 저장(Commit changes)합니다. 폴더 자체를 한 단계 더 넣지 마세요. `.nojekyll`도 함께 추가할 수 있습니다.
3. 저장소의 **Settings → Pages → Build and deployment**로 이동합니다.
4. Source는 **Deploy from a branch**, Branch는 **main**, 폴더는 **/(root)**를 선택하고 **Save**를 누릅니다.
5. 배포가 완료되면 Pages 화면에 표시되는 사이트 주소를 엽니다. 일반적으로 `https://사용자이름.github.io/gamttiz/` 형태입니다.

공식 안내: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

현재는 로컬 제작본이며 GitHub 업로드 및 공개 배포는 아직 수행하지 않았습니다.

## 수정 위치

- 브랜드 소개 및 페이지 구성: `index.html`
- 색상, 간격, 반응형 화면: `style.css` 및 `refinement.css`
- 제품 이름 및 설명: `app.js`의 `products`
- 원본 이미지: `assets/`

이미지는 원본 파일을 그대로 복사했습니다. 색상 보정, 재생성, 자르기, 회전은 하지 않았으며 화면 너비에 맞춰 같은 비율로 표시됩니다. 갤러리에서 클릭하면 상세 화면, 원본 이미지 링크, 이전/다음 이동을 사용할 수 있습니다. Esc로 닫고 좌우 방향키로 이동할 수 있습니다.

키링 파일 번호는 제공된 Artboard 번호와 같습니다. `holder.png`는 Artboard 1.png, `brand.png`는 감띠즈 인스타.png, `badge.png`는 감띠즈 인스타 프사.png입니다. `brand-red.png`와 `brand-white.png`는 제공된 22.png, 33.png의 보존본입니다.

브랜드 소개 문구는 사이트 초안용 제안 문구입니다. 제품명과 제품 설명은 제공된 이미지에 근거했습니다. 가격, 판매 재고, 구매 및 결제 기능은 포함하지 않았습니다.

## 레퍼런스 반영 수정본

밝은 배경, 01–03 교차 제품 소개, 여백 중심 구성으로 수정했습니다. 한글은 맑은 고딕(Apple 기기에서는 Apple SD Gothic Neo)을 사용합니다. 영문 로고와 포인트에는 사용자가 제작한 감띠즈 영문 Regular/Bold를 WOFF2로 변환해 적용했습니다. 웹폰트와 라이선스는 assets/fonts 안에 포함되어 있습니다. 기존 PNG 19개는 변경하지 않았으며 추가 생성 이미지는 사용하지 않았습니다.


## 컬러·영상·플레이 업데이트

- 레드·옐로 팔레트를 첫 화면, 흐르는 문구, 트레이, 하단에 적용했습니다.
- 6초 무음 MP4 브랜드 영상은 전용 영문 글자와 새 도형으로 제작했습니다. 기존 캐릭터 이미지는 영상에 재생성하거나 합성하지 않았습니다.
- 영상이 화면에 들어오면 재생하고, 화면 밖이나 다른 탭으로 이동하면 정지합니다. 운영체제의 움직임 줄이기 설정을 존중합니다.
- 트레이에는 최대 3종을 담을 수 있습니다. 데스크톱은 클릭 또는 드래그, 모바일은 탭, 키보드는 Tab과 Enter/Space를 사용합니다. 선택은 새로고침하면 초기화됩니다.
- 비밀 노트는 트레이에 선택한 감띠의 이름과 설명을 바로 표시하며, 선택 해제·초기화도 함께 반영합니다. 제품 고르기·홀더 활용·공식 소식 안내를 추가했습니다.
- 영상 및 작은 애니메이션: assets/brand-loop.mp4, play.css, play.js.
- 가격이나 주문 기능은 없습니다. 트레이는 조합 체험이며 판매 세트가 아닙니다.

검증: 브라우저에서 최대 3개 선택·초과 선택 안내·제거·초기화, 실제 드래그, 이야기 카드와 상세 연결, 영상 재생·일시정지, 모바일 화면 너비를 확인했습니다. 모바일은 축소 화면에서 확인했으며 실제 휴대폰에서는 별도 확인이 필요합니다.

## 주석 반영

첫 제목을 We Love French Fry로, 상단 메뉴를 영어로 변경했습니다. 첫 화면과 홀더 버튼은 노랑 배경·흰 글씨이며 뽑기 버튼을 강조하고 캐릭터 이름을 굵게 표시했습니다. 움직임 버튼, 영상 캡션, 하단 원형 이미지를 제거했습니다. 트레이와 비밀 노트 연동 및 상세 연결, 모바일 가로 넘침 없음을 브라우저에서 확인했습니다.
